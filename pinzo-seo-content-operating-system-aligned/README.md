# Pinzo SEO Content Operating System — Strategy-Aligned Skill

This skill generates publish-ready cornerstone SEO content for Pinzo based on the comprehensive Pinzo SEO strategy workbook.

## What changed in this aligned version

The skill is now directly aligned to:

- Pinzo's keyword universe.
- Cluster summary and strategic thesis.
- P1/P2/P3 page roadmap.
- 180-day content calendar.
- Programmatic SEO rollout rules.
- Internal linking architecture.
- Page template quality bars.
- CRO lead magnets.
- Technical SEO checklist.
- Backlink and distribution plan.

## How to use

Use prompts like:

- "Generate the P1 page for `/guides/google-business-profile-optimization-checklist/`."
- "Create a CMS-ready page for the keyword `google my business verification`."
- "Take week 1 from the content calendar and generate the page brief."
- "Create a cornerstone page for doctors and clinics aligned to the roadmap."
- "Optimize this existing Pinzo page against the skill and publish-readiness score."

## Core rule

Do not create generic SEO content. Every important Pinzo page should be a cornerstone asset with strategy-mapped URL, search intent, examples, internal links, CTA, lead magnet, schema, and a publish-readiness score.
