## Required generation behavior

- If the user asks for a keyword that appears in `strategy/keyword-mapping.csv`, generate content for its mapped URL and page type.
- If the keyword maps to `/google-business-profile-management-tool/`, treat it as a product authority hub or a supporting section, not a separate article, unless the keyword has a separate intent that deserves a support page.
- If the roadmap has a CTA, use it exactly or improve only slightly while preserving the intent.
- Use the roadmap `Content Modules`, `Internal Links`, `Schema`, and `Moat / Differentiator` fields as mandatory inputs.
- If mapped volume and business fit are available, surface them in the content brief but do not publish them on the page unless the user asks.
