# Pinzo Publish-Readiness Scorecard

Use this score before marking any page as publish-ready.

## Thresholds

| Page Class | Threshold |
|---|---:|
| P1 cornerstone page | 90+ |
| P2 strategic page | 85+ |
| P3/support page | 80+ |
| Programmatic page | 85+ plus uniqueness safeguards |

## Scoring

| Category | Points |
|---|---:|
| Strategy alignment | 20 |
| Search intent satisfaction | 15 |
| Content depth and usefulness | 15 |
| Original Pinzo moat/tool/checklist | 15 |
| Internal linking | 10 |
| CTA and lead magnet | 10 |
| AIO/GEO/AEO structure | 10 |
| Technical/CMS readiness | 5 |
| Total | 100 |

## Automatic fail conditions

A page cannot be marked publish-ready if:

- It maps to the wrong URL.
- It creates cannibalization against a roadmap URL.
- It has no lead magnet or CTA.
- It has no internal links.
- It is generic AI copy.
- It lacks examples/checklists/templates.
- It claims unconfirmed Pinzo features as live.
- It impersonates Google.
- It promises guaranteed review removal, ranking, verification, or reinstatement.
- A pSEO page uses swapped city/industry names without unique content.

## Required final output

Return:

- Score.
- Threshold.
- Pass/fail.
- Missing items.
- Fixes needed before live.
- Suggested update frequency.
