# Pinzo pSEO Master Template

## Page type

Industry × City commercial landing page

## URL pattern

`/google-business-profile-management-for-{industry_slug}-in-{city_slug}/`

Example:

`/google-business-profile-management-for-doctors-clinics-in-mumbai/`

## Primary intent

Users searching this page are usually looking for one of three things:

1. Someone to manage their Google Business Profile in their city.
2. A tool/system to improve local visibility, reviews, posts, photos, and profile completeness.
3. A practical understanding of what GBP management should look like for their industry.

The page must satisfy all three without becoming a generic location-swapped page.

# Required schema markup

Every published industry × city pSEO page must output one combined JSON-LD graph.

Required schema stack:

1. `WebPage`
2. `BreadcrumbList`
3. `Service`
4. `Organization`
5. `SoftwareApplication`

Optional schema stack, only when visible page content supports it:

- `FAQPage` — only when the FAQ section is visible on the page. Use for entity clarity; do not expect FAQ rich results for most commercial pages.
- `ItemList` — only when the page has a visible checklist, post ideas list, audit checklist, or module list.
- `Offer` — only when the page clearly shows a free audit, demo, consultation, pricing, or package.
- `VideoObject` — only when a real video is embedded with required fields.
- `ImageObject` — only for meaningful original images/screenshots.

Do **not** use by default:

- `LocalBusiness` — do not use this just because the page targets a city. Use it only if Pinzo has a truthful local office or service-area presence for that city. For most pSEO pages, `Service` with `areaServed` is safer.
- `Review` / `AggregateRating` — do not add fake ratings or self-created reviews. Use only when legitimate reviews are visible and compliant.
- `HowTo` — not the default for this page pattern because these are commercial service pages, not pure how-to instructions.

Required schema files in this package:

- `schema_markup_guide.md` — full implementation rules for Bhav/dev team.
- `json_ld_templates.json` — reusable JSON-LD graph templates for mass production.

Required schema output fields:

1. `schema_jsonld.required_graph`
2. `schema_jsonld.optional_graph_addons`
3. `schema_jsonld.validation_status`
4. `schema_jsonld.validation_notes`

Schema QA rule:

The page cannot be marked `ready_to_publish` unless schema is valid JSON-LD, matches visible content, and passes the schema checklist in `schema_markup_guide.md`.
